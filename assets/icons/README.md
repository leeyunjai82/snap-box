# 얼굴 대체 그림

보고서에 넣을 때 얼굴 자리에 얹는 그림입니다. 전부 자체 제작했습니다.

## 그리는 규칙

- **표식 규격**: 지름 116의 흰 원판(`#FFFFFF`) + 본문색 테두리(`#1C2024`, 5px) 위에
  브랜드 남색(`#1F5F7A`) 글리프 하나. 다섯 개가 한 벌로 보이도록 원판은 모두 같습니다.
- 사진 위에 얹히므로 **원판은 반드시 불투명**해야 합니다. 대비가 낮으면 사진에 묻힙니다.
- 색은 `css/maker-tool.css` 토큰 값만 씁니다. 새 색을 만들지 않습니다.
  (`--panel #FFFFFF` · `--ink #1C2024` · `--acc #1F5F7A`)
- `viewBox="0 0 128 128"`, `width`/`height` 속성 필수 — 없으면 캔버스에 못 그립니다.
- 그림자·그라디언트·이모지 금지.

## 가림은 그림이 아니라 바탕이 책임집니다

그림은 장식이고, 실제로 얼굴을 덮는 것은 그 아래 깔리는 모자이크입니다
(`js/face.js` 의 `buildPatch`). 그림이 칸을 다 못 채워도 얼굴이 새지 않습니다.
그림만 얹고 바탕을 빼는 식으로 고치지 마세요.

## js/face.js 와 같이 고칠 것

이 폴더의 SVG와 **똑같은 내용**이 `js/face.js` 의 `ICON_SVG` 에 data: URI 로 들어 있습니다.
`file://` 로 열었을 때 로컬 SVG 파일을 캔버스에 그리면 캔버스가 오염되어(tainted)
`toBlob()` 이 SecurityError 로 실패하기 때문입니다.

**이 폴더를 고치면 `js/face.js` 의 `ICON_SVG` 도 같이 고쳐야 합니다.**

# 더 메이커 **업무 도구 킷** — snap-box · clip-box

교육용 킷과 **같은 집안, 다른 킷**입니다.
`sense-lab` · `pibo-lab` 은 학생이 쓰는 **교육 도구**, `snap-box` · `clip-box` 는
교사·담당자가 업무로 쓰는 **사무 도구**입니다. 한 회사 제품인 것은 보이되,
업무 화면에 학습지 장식이 따라오지는 않게 합니다.

- 이 킷: [`css/maker-tool.css`](../css/maker-tool.css) — **한 파일을 복사해 그대로** 씁니다.
- 컴포넌트 실물: [`preview.html`](./preview.html) — 서버로 띄워서 봅니다.
- 교육용 킷 규격(참고): [`maker-ui.README.md`](./maker-ui.README.md)
  (원본: `themakerrobot/sense-lab` → `design/maker-ui.css` · `design/README.md`)

---

## 1. 두 킷의 관계

**토큰 이름과 클래스 이름이 같습니다.** 값과 장식만 다릅니다.
그래서 서비스는 CSS 한 줄만 바꿔 결을 고릅니다. 마크업은 거의 그대로 돕니다.

```html
<!-- 교육용 -->  <link rel="stylesheet" href="css/maker-ui.css">
<!-- 업무용 -->  <link rel="stylesheet" href="css/maker-tool.css">
```

### 계승하는 것 — 여기를 건드리면 한 집안으로 안 보입니다

| | 값 |
|---|---|
| 브랜드 남색 | `--acc #1F5F7A` · `--acc-ink #12455C` · `--acc-soft #E6EEF6` |
| 성공 · 경고 | `--ok #2E7D4F` · `--warn #B4451C` |
| 본문 글꼴 | Pretendard (셀프호스팅) |
| 아이콘 | Font Awesome 6 Free **Solid** 만 |
| 브랜드 남색 마크 | 서비스마다 하나씩, 같은 형태 규칙 (§5) |
| 헤더 구성 | 로고 + 서비스명 + 부제 + 상태 배지 + 전체화면 + 한/영 |
| 클래스 이름 | `.db .inp .pan .ph .pb .hint .sec2 .row .prg .badge .dropzone .navlink …` |
| 토큰 이름 | `--bg --panel --panel2 --line --line-soft --line-d --ink --ink2 --ink3 --acc …` |

### 바꾸는 것

| | 교육용 (학습지) | 업무용 (사무) |
|---|---|---|
| 로고 | 파이보 캐릭터 (마스코트) | 서비스 마크 (§5) |
| 바탕 | 미색 종이 `#FBF7EF` + 점무늬 | 무지 회백 `#F1F3F5`, 무늬 없음 |
| 테두리 | 갈색 괘선 `#4A3F2E` | 회색 `#D5D9DF` / `#C6CAD1` |
| 본문색 | `#2A2620` (따뜻한 먹) | `#1C2024` (중립 먹) |
| 서비스명 | 명조 (`--serif`) | Pretendard — **`--serif` 토큰 자체를 없앴습니다** |
| 헤더 | 갈색 2px 외곽선 상자, 사방 8px 띄움 | 흰 바 + 아래 1px 경계선, 화면 끝까지 |
| 단계 표시 | `.steps` 원형 번호 + 잇는 선 | `.tabbar` 밑줄 탭 + 숫자 (끝나면 초록 체크) |
| 모서리 | 6 ~ 12px | 4 ~ 6px |
| 기본 글자 | 13.5px | 13px |
| 패널 머리줄 | 투명 배경 | `--panel2` 면 + 경계선 |

## 2. 말투 — 킷보다 이게 더 티가 납니다

| | 교육용 | 업무용 |
|---|---|---|
| 어미 | 해요체 | **합니다체 존댓말** |
| 길이 | 한 문장 20자 | 한 문장 40자까지 |
| 용어 | 쉬운 말 (종류·예시·배우기) | **실무어 그대로** (해상도, 품질, EXIF, 일괄) |
| 지시 | 한 화면에 하나 | 설정이 한눈에 |

- 교육용: "사진을 여기에 놓아 보세요"
- 업무용: "사진을 여기에 놓거나 눌러서 고릅니다"

### 지키는 것

- 결론 먼저, 이유는 뒤에. "칸 수가 적을수록 더 많이 가립니다."
- 부정문보다 긍정문. "누르지 마세요" → "적용한 뒤에 누릅니다"
- 실패 문구는 **다음에 할 일**까지.
  "얼굴 찾기를 불러오지 못했습니다. 주소창이 file:// 이면 http:// 로 열어 주세요"
- 버튼은 **짧은 동사구**. "이 사진에" / "전체에" / "대지 만들기"

### 쓰지 않는 말

손쉽게 · 간편하게 · 스마트한 · 완벽하게 · 최적화 · 강력한 · 혁신적인 · 한 번에 뚝딱.
이모지 장식(`✨ 🚀 ✅`) 금지. 느낌표는 한 화면에 0개.

## 3. 화면 뼈대

```
header        로고 + 서비스명 + 부제 + [상태 배지] [전체화면] [한/영]
.tabbar       1 → 2 → 3 → 4   작업 탭. 지나온 작업은 .done
.mk-main      .pan-side(목록) + .pan-wide(작업 대상) + .pan-out(도구)
.mk-bar       이전/다음 · 주 동작 · 되돌리기 · 원본으로 · 일괄 · 진행률
```

- **작업 탭과 도구 탭을 따로 두지 않습니다.** `.tabbar` 가 곧 오른쪽 패널의 탭입니다.
  같은 이동을 두 군데 두면 어디를 눌러야 할지 헷갈립니다.
- 오른쪽 패널 `.ph` 는 지금 탭의 이름과 아이콘을 그대로 비춥니다.
- 주 동작(`.db.go`)은 **할 일이 있을 때만** 열어 두고, 있으면 `.pending` 으로 점을 붙입니다.
- 되돌릴 수 없는 동작(모두 비우기 · 원본으로)은 `confirm()` 으로 한 번 묻습니다.
- 대상이 없으면 도구 버튼을 **잠급니다**. 눌러 봐야 안내만 뜨는 버튼을 열어 두지 않습니다.

## 4. 킷에 들어 있는 것

교육용 킷에 없던 것도 업무 도구가 공통으로 쓰므로 **킷 안에** 넣었습니다.
서비스 전용 CSS(`css/app.css`)에 다시 만들지 마세요.

| 클래스 | 쓰임 |
|---|---|
| `.hbtn` | 헤더 아이콘 버튼 |
| `.tabbar > .tab` | 작업 탭 (`.on` 지금, `.done` 끝남, `.n` 번호) |
| `.pan > .pf` | 패널 바닥 줄 |
| `.ph-count` `.ph-meta` `.ph-sp` | 패널 머리줄 부속 |
| `.mk-bar` | 아래 작업 줄 (`.bar-div` 구분선, `.bar-sp` 여백, `.db.pending`) |
| `.rangerow` | 라벨 + 슬라이더 + 숫자 한 줄 |
| `.fieldrow` | 라벨 + 입력칸(+`.unit`) 한 줄 |
| `.minirow > .mini` | 작은 입력 여러 개 |
| `.pickrow` | `.db` 여러 개 중 하나 고르기 |
| `.filebtn` | `input[type=file]` 을 받는 label (잠글 때 `.off`) |
| `.summary > .srow > .sk + .sv` | 지금 설정 요약표 |
| `.namepv` | 결과 미리보기 한 줄 (등폭) |
| `.dropzone` (`.over` `.slim`) | 파일 놓는 자리 |
| `#busy > .busy-box` | 처리 중 가림막 |
| `[hidden]{display:none !important}` | `display:flex` 요소에 `hidden` 이 먹게 |

**서비스 전용으로 남기는 것**: 그 서비스의 데이터에만 있는 줄·무대.
snap-box 는 `.qitem`(사진 목록 줄), `.pb-stage`(미리보기 무대), `.iconpick`(얼굴 대체 그림)만 남겼습니다.

## 5. 서비스 마크

파이보 캐릭터는 **교육 서비스(sense-lab · pibo-lab)의 마스코트**입니다.
업무 도구에는 쓰지 않습니다. 이유는 둘입니다.

- 볼터치·벌린 입은 §1에서 걷어낸 학습지 결이고, 업무 화면과 어긋납니다.
- 16px 브라우저 탭 아이콘에서 형태가 무너집니다. 탭이 여러 개 열린 업무 환경에서
  무엇인지 못 알아봅니다.

대신 서비스마다 마크를 하나씩, **같은 형태 규칙**으로 그립니다.
브랜드 남색을 그대로 쓰므로 한 집안으로 보이고, 작은 크기에서도 형태가 남습니다.

### 형태 규칙

```
viewBox   0 0 40 40  (정사각, width/height 속성 필수)
바탕      rect 0,0,40,40  rx 9.5   fill --acc #1F5F7A
안쪽 판   rect 7.5,10,25,20  rx 3   fill #FFFFFF        ← "box" 를 나타내는 공통 판
글리프    흰 판 안에만. fill --acc. 보조 톤이 필요하면 같은 색 opacity .38
```

- **색은 남색 하나**입니다. 새 색을 만들지 않고, 밝은 톤이 필요하면 불투명도로 만듭니다.
- 글리프는 **그 도구가 하는 일**을 그립니다. 회사도, 캐릭터도 아닙니다.
- 획은 최소 3px(40 기준). 16px로 줄여 보고 뭉개지면 다시 그립니다.

| 서비스 | 글리프 | 파일 |
|---|---|---|
| snap-box | 사진 판 + 모자이크 칸 6개 | [`../assets/img/snap-box-mark.svg`](../assets/img/snap-box-mark.svg) |
| clip-box | 사진 판 + 재생 삼각형 + 필름 구멍 | [`mark/clip-box-mark.svg`](./mark/clip-box-mark.svg) (본보기) |

### 쓰는 곳

```html
<!-- 헤더: js/nav.js 의 MARK 상수 -->
<link rel="icon" type="image/svg+xml" href="assets/img/<서비스>-mark.svg">
<link rel="icon" type="image/png" sizes="64x64" href="assets/img/icon-64.png">
<link rel="apple-touch-icon" href="assets/img/icon-180.png">
```

PNG(64 · 180 · 512)는 SVG 파비콘을 못 읽는 곳을 위해 SVG에서 뽑아 둡니다.
**SVG를 고치면 PNG도 다시 뽑습니다.**

## 6. 코드 규약

### 파일 놓는 자리

```
index.html
css/     maker-tool.css(킷 사본, 수정 금지) · app.css(서비스 전용) · all.min.css(FA)
webfonts/                      FA 웹폰트
assets/fonts/ assets/img/      Pretendard · 로고
js/      nav.js i18n.js + 기능별 파일
vendor/                        라이브러리 셀프호스팅
models/                        모델·wasm 셀프호스팅
design/                        이 문서 · preview.html
```

### 경로

- **전부 상대경로.** `/vendor/...` 는 GitHub Pages 하위 경로에서 깨집니다.
- 계정명·저장소명을 코드에 박지 않습니다. 다른 서비스로 가는 링크도 넣지 않습니다
  (배포 경로가 서로 달라 절대경로를 박아야 하는데, 그게 금지입니다).
- classic script 안의 동적 `import()` 는
  `new URL('vendor/x.mjs', document.baseURI).href` 로 **문서 기준**으로 풀어야 합니다.
  `'./vendor/x.mjs'` 라고 적으면 문서가 아니라 **그 스크립트 파일** 기준으로 풀려 404 가 납니다.

### 스크립트 로딩 — ES modules 를 쓰지 않는 이유

Chrome 은 `file://` 오리진의 `<script type="module">` 을 CORS 로 막습니다.
`index.html` 을 더블클릭해도 돌아가야 하므로, `js/` 는 **classic script + 전역 네임스페이스**
(`window.SnapLab` / `window.ClipBox` …)로 싣습니다. 파일은 기능별로 나눕니다.
`import()` 는 꼭 필요한 곳(MediaPipe 등)만 쓰고, 실패하면 **그 기능만** 끕니다.

### 다국어

sense-lab `lib/i18n.js` 규약을 두 킷이 함께 씁니다.

- **한국어 원문이 곧 키.** 사전에 없으면 한국어가 그대로 나옵니다.
- HTML 은 손대지 않고, 뜨고 나서 DOM 텍스트를 바꿔치기합니다.
- 저장 키는 서비스가 달라도 **`language`** 하나. 도구를 오가도 언어가 유지됩니다.
- 번역할 문장 안에 `<span>` 같은 인라인 요소를 넣지 않습니다. 텍스트 노드가 쪼개져 키가 안 맞습니다.
- 값이 들어가는 문장은 `GL_TF('{n}장 모두 했습니다', {n:3})`.

### 저장 키

| 키 | 내용 |
|---|---|
| `language` | `ko` / `en` — **모든 서비스 공용** |
| `<서비스>.settings` | 그 서비스의 마지막 설정값 (`snapbox.settings`) |

사용자가 만든 내용물(사진·영상·문서)은 **절대 저장하지 않습니다.** 새로고침하면 사라집니다.

### 서비스가 직접 그리는 그림 (캔버스·SVG)

- 색은 킷 토큰 값을 **그대로 적습니다.** CSS 변수를 못 읽는 자리(캔버스 2D, fabric 설정)라도
  `#1F5F7A` 처럼 같은 값을 쓰고, 옆에 어떤 토큰인지 주석을 답니다.
- 사진·영상 위에 얹는 표식은 **불투명**해야 합니다. 대비가 낮으면 묻힙니다.
- 캔버스에 올릴 SVG 는 `data:` URI 로 내장합니다. `file://` 에서 로컬 SVG 를 그리면
  캔버스가 오염되어 `toBlob()` 이 막힙니다.

## 7. 개인정보 — 업무 도구의 1원칙

교육 현장 자료를 다루므로 **내용물이 브라우저 밖으로 나가지 않는다**가 첫 번째입니다.

- 서버·API 호출 금지. 라이브러리와 모델은 전부 `vendor/` · `models/` 에 셀프호스팅해서
  **실행 중 바깥으로 나가는 요청이 0개** 여야 합니다.
- 모델은 **이름만 보고 고르지 말고 재 보세요.** snap-box 는 처음에 MediaPipe 기본값인
  `blaze_face_short_range` 를 썼는데, 이름 그대로 2m 이내용이라 교실 단체사진에서
  검출률이 0 이었습니다. `blaze_face_full_range` 로 바꾸고 나서야 쓸 만해졌습니다
  (풀레인지는 `tasks-vision` 1.0.1 이상이 필요합니다. 0.10.x 는 디코딩에서 터집니다).
  자기 현장 사진에 가까운 조건으로 검출률 표를 한 번 만들어 보고 정하세요.
- 내보내는 파일은 항상 캔버스로 다시 인코딩해 촬영 정보(EXIF·GPS)를 떨굽니다.
- 첫 화면에 한 줄로 밝힙니다.
  "사진은 이 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다."
- 가림·지움 같은 되돌릴 수 없는 처리는 **미리보기로 두고 "적용" 을 눌러야** 원본에 굽습니다.

## 8. 새 도구를 만들 때 (clip-box 등)

1. `css/maker-tool.css` · `css/all.min.css` · `webfonts/` · `assets/fonts/` 를 복사합니다.
2. §5 규칙으로 서비스 마크를 그리고, PNG 파비콘 3종을 뽑습니다.
   (`design/mark/clip-box-mark.svg` 가 본보기입니다)
3. `js/nav.js` 를 복사해 `BRAND` · `MARK` · `TABS` 만 고칩니다.
4. `js/i18n.js` 를 복사해 사전만 갈아 끼웁니다. 구조는 건드리지 않습니다.
5. `index.html` 의 뼈대(§3)를 그대로 따릅니다.
6. 서비스 전용 CSS 는 `css/app.css` 하나에만 씁니다. 킷을 고치지 않습니다.
7. `design/preview.html` 을 복사해 두고, 새 컴포넌트를 만들면 여기에 먼저 올립니다.

## 9. 하지 않는 것

- 새 색상·새 폰트·새 그라디언트
- 이모지 장식, 알약형 상태 배지 남발
- React/Vue/빌드 도구
- 절대경로, 계정명 하드코딩
- 같은 이동 수단을 두 군데 두기 (작업 탭 + 도구 탭)
- 로그인·서버·DB·계정
- 업무 도구에 교육 마스코트 쓰기
- 킷 파일(`maker-tool.css`) 직접 수정 — 필요하면 킷에 올리고 세 서비스가 같이 받습니다

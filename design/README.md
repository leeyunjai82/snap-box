# 더 메이커 도구 디자인 기준 — snap-box · clip-box

`sense-lab` / `pibo-lab` 과 **한 제품으로 보이게** 하는 규격입니다.
새 도구를 만들 때는 새로 디자인하지 말고 이 문서대로 복사해 씁니다.

- 공통 킷 원본: [`themakerrobot/sense-lab` → `design/maker-ui.css`](https://github.com/themakerrobot/sense-lab)
  이 저장소의 [`css/maker-ui.css`](../css/maker-ui.css) 는 그 사본입니다. **고치지 않습니다.**
- 킷 규격 원문: [`maker-ui.README.md`](./maker-ui.README.md) (sense-lab `design/README.md` 사본)
- 컴포넌트 실물: [`preview.html`](./preview.html) — 서버로 띄워서 봅니다.

이 문서는 그 위에 **도구형 서비스(snap-box·clip-box)** 에만 해당하는 것을 더합니다.

---

## 1. 학습용 서비스와 도구형 서비스의 차이

색·글꼴·컴포넌트는 **완전히 같습니다.** 다른 것은 두 가지뿐입니다.

| | sense-lab (학습용) | snap-box · clip-box (도구형) |
|---|---|---|
| 쓰는 사람 | 초등학생 | 교사·담당자 (사무 업무) |
| 말투 | 해요체, 한 문장 20자 | **합니다체 존댓말**, 한 문장 40자까지 |
| 용어 | 쉬운 말 (종류·예시·배우기) | **실무어 그대로** (해상도, 품질, EXIF, 일괄) |
| 화면 밀도 | 여유 있게, 지시 하나씩 | **빽빽하게**, 설정이 한눈에 |
| 흐름 | 단계를 순서대로 밟음 | 단계를 **오가며** 씀 |

말투 예:

- 학습용: "사진을 여기에 놓아 보세요"
- 도구형: "사진을 여기에 놓거나 눌러서 고릅니다"

### 문구를 쓸 때 지키는 것

- 결론 먼저, 이유는 뒤에. "칸 수가 적을수록 더 많이 가립니다."
- 부정문보다 긍정문. "누르지 마세요" → "적용한 뒤에 누릅니다"
- 실패 문구는 **다음에 할 일**까지. "얼굴 찾기를 불러오지 못했습니다. 주소창이 file:// 이면 http:// 로 열어 주세요"
- **쓰지 않는 말**: 손쉽게, 간편하게, 스마트한, 완벽하게, 최적화, 강력한, 혁신적인.
  이모지 장식 금지 (`✨ 🚀 ✅` 등). 느낌표는 한 화면에 0개.
- 버튼 이름은 **동사로 끝나는 짧은 말**. "이 사진에" / "전체에" / "대지 만들기".

## 2. 화면 뼈대 (도구형 공통)

```
header                      로고 + 서비스명 + 부제 + [준비 배지] [전체화면] [한/영]
#steps                      1 → 2 → 3 → 4   (눌러서 도구를 바꾼다. 지나온 단계는 .done)
.mk-main                    .pan-side(목록) + .pan-wide(미리보기) + .pan-out(도구)
.mk-bar                     이전/다음 · 적용 · 되돌리기 · 원본으로 · 일괄 · 진행률
```

- **단계와 탭을 따로 두지 않습니다.** `#steps` 가 곧 도구 패널의 탭입니다.
  같은 이동을 두 군데 두면 어디를 눌러야 할지 헷갈립니다.
- 오른쪽 패널의 `.ph` 는 현재 단계 이름과 아이콘을 그대로 비춥니다.
- 되돌릴 수 없는 동작(모두 비우기, 원본으로)은 `confirm()` 으로 한 번 묻습니다.

## 3. 킷에 올릴 후보 — 도구형에서 새로 만든 것

`css/app.css` 에 있고, `maker-ui.css` 에는 아직 없는 것들입니다.
clip-box 도 필요하면 **같은 이름으로** 가져다 쓰고, 셋 이상 쓰게 되면 킷으로 올립니다.

| 클래스 | 쓰임 |
|---|---|
| `.hbtn` | 헤더 아이콘 버튼. sense-lab `css/ui.css` 에 있는 것을 값 그대로 옮긴 것 |
| `.pan > .pf` | 패널 바닥 줄 (목록 아래 "고른 것 빼기" 같은 것) |
| `.mk-bar` | 3단 패널 아래 작업 줄. `.bar-div` 구분선, `.bar-sp` 여백 |
| `.rangerow` | 라벨 + 슬라이더 + 숫자 한 줄 |
| `.fieldrow` | 라벨 + 입력칸(+단위) 한 줄 |
| `.pickrow` | `.db` 여러 개 중 하나 고르기 (`.on` = 고른 것) |
| `.summary` | 지금 설정 요약표 (`.srow > .sk + .sv`) |
| `.qitem` | 썸네일 목록 한 줄 (체크 + 번호 + 그림 + 이름·상태) |
| `.iconpick` | 정사각 그림 고르기 판 |
| `.namepv` | 결과 미리보기 한 줄 (등폭) |
| `.filebtn` | `input[type=file]` 을 받는 label. 잠글 때는 `.off` |

`[hidden]{display:none !important}` 한 줄도 `app.css` 맨 위에 둡니다.
`display:flex` 를 준 요소에 `hidden` 속성만 걸면 안 사라집니다.

## 4. 색 · 글꼴 · 아이콘

- 색은 [`maker-ui.README.md`](./maker-ui.README.md) 의 토큰만 씁니다. **새 색을 만들지 않습니다.**
  캔버스에 직접 그리는 색(`fabric` 조절점, 스탬프 바탕 등)도 토큰과 같은 값을 적습니다.
  - 조절점·테두리 `#1F5F7A` (`--acc`) / 자르기 틀 `#B4451C` (`--warn`) / 스탬프 바탕 `rgba(42,38,32,.62)` (`--ink`)
- 글꼴은 Pretendard(본문) + 명조(서비스명). 셀프호스팅. **새 폰트 금지.**
- 아이콘은 **Font Awesome 6 Free Solid** (`fa-solid`) 만 씁니다.
  `fa-regular` · `fa-brands` 는 웹폰트를 넣지 않았으니 쓰지 않습니다.
- 서비스가 직접 그리는 SVG(얼굴 대체 그림 등)는 [`assets/icons/README.md`](../assets/icons/README.md)
  의 **도장 규격**을 따릅니다 — 미색 원판 + 갈색 테두리 + 남색 글리프.

## 5. 코드 규약

### 파일 놓는 자리

```
index.html
css/   maker-ui.css(사본, 수정 금지) · app.css(서비스 전용) · all.min.css(FA)
webfonts/                      FA 웹폰트
assets/fonts/ assets/img/      Pretendard · 로고
js/    nav.js i18n.js + 기능별 파일
vendor/                        라이브러리 셀프호스팅
models/                        모델·wasm 셀프호스팅
design/                        이 문서 · preview.html
```

### 경로

- **전부 상대경로.** `/vendor/...` 같은 절대경로는 GitHub Pages 하위 경로에서 깨집니다.
- 계정명·저장소명을 코드에 박지 않습니다.
- classic script 안에서 동적 `import()` 를 쓸 때는
  `new URL('vendor/x.mjs', document.baseURI).href` 로 **문서 기준**으로 풀어야 합니다.
  `'./vendor/x.mjs'` 라고 적으면 문서가 아니라 **그 스크립트 파일** 기준으로 풀려 404 가 납니다.

### 스크립트 로딩 — ES modules 를 쓰지 않는 이유

Chrome 은 `file://` 오리진의 `<script type="module">` 을 CORS 로 막습니다.
`index.html` 을 더블클릭해도 돌아가야 하므로, `js/` 는 **classic script + 전역 네임스페이스**
(`window.SnapLab` / `window.ClipBox` …) 로 싣습니다. 파일은 기능별로 나눕니다.
`import()` 는 꼭 필요한 곳(MediaPipe)만 쓰고, 실패하면 그 기능만 끕니다.

### 다국어

sense-lab `lib/i18n.js` 규약을 그대로 씁니다.

- **한국어 원문이 곧 키.** 사전에 없으면 한국어가 그대로 나옵니다.
- HTML 은 손대지 않고, 뜨고 나서 DOM 텍스트를 바꿔치기합니다.
- 저장 키는 서비스가 달라도 **`language`** 하나. (도구를 오가도 언어가 유지됩니다)
- 번역할 문장 안에 `<span>` 같은 인라인 요소를 넣지 않습니다. 텍스트 노드가 쪼개져 키가 안 맞습니다.
- 값이 들어가는 문장은 `GL_TF('{n}장 모두 했습니다', {n:3})`.

### 저장 키

| 키 | 내용 |
|---|---|
| `language` | `ko` / `en` — **모든 서비스 공용** |
| `<서비스>.settings` | 그 서비스의 마지막 설정값 (`snapbox.settings`) |

사용자가 만든 내용물(사진·영상·문서)은 **절대 저장하지 않습니다.** 새로고침하면 사라집니다.

## 6. 개인정보 — 도구형의 1원칙

교육 현장 자료를 다루므로 **내용물이 브라우저 밖으로 나가지 않는다**가 첫 번째입니다.

- 서버·API 호출 금지. 라이브러리와 모델은 전부 `vendor/` · `models/` 에 셀프호스팅.
  실행 중 바깥으로 나가는 요청이 **0개** 여야 합니다.
- 내보내는 파일은 항상 캔버스로 다시 인코딩해 촬영 정보(EXIF·GPS)를 떨굽니다.
- 첫 화면에 한 줄로 밝힙니다:
  "사진은 이 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다."
- `file://` 로 열어도 되도록 만듭니다. 로컬 SVG 를 캔버스에 그리면 캔버스가 오염되어
  `toBlob()` 이 막히므로, 캔버스에 올릴 그림은 `data:` URI 로 내장합니다.

- 새 색상·새 폰트·새 그라디언트
- 이모지 장식, 알약형 상태 배지 남발
- React/Vue/빌드 도구
- 절대경로, 계정명 하드코딩
- 같은 이동 수단을 두 군데 두기 (단계 + 탭)
- 로그인·서버·DB·계정
